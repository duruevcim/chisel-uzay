## 3. GNU Radio Binary Dosyası Üretimi

`qpsk_0x55.cf32` Drive üzerinden iletilmiş, hocada çalışmamıştır. Mevcut script `.bin` uzantılı çıktı üretmesi için çağrıldı:

```
python -c "from gen_if_data import generate; generate(out_path='qpsk_0x55.bin')"
```

**Dosya parametreleri:**

| Parametre | Değer |
|---|---|
| Idle pattern | 0x55 = 01010101 |
| Symbol rate | 10,000 sps |
| Samples per symbol | 4 |
| Sample rate | 40,000 sps |
| Süre | 10 saniye |
| Toplam sample | 400,000 |
| Format | complex float32, little-endian |
| Boyut | 3.2 MB |

GNU Radio File Source ayarları: **Output type:** Complex Float 32, **Sample rate:** 40000

## 4. Teknik Tartışmalar

**QPSK Fixed-Point Temsili**
- 14-bit DAC: `FULL_SCALE = 8191`, `SYMBOL_SCALE = 5792` (= 8191/√2, unit energy koşulundan)
- I ve Q ayrı ayrı 14-bit signed integer — her kanal 1 bit veri taşıyor
- 14-bit hassasiyet analog kalite için, veri kapasitesi için değil

**RF Sinyal Zinciri**
- FPGA → DAC → Mixer → Amplifier → Anten
- DAC baseband analog üretir, Mixer RF frekansına taşır: I×cos(2πft) + Q×sin(2πft)
- Alıcı: analog sinyal → ADC → demodülatör → 2 bit karar

**Frekans, Enerji, Güç**
- Kuantum: E = hf (foton enerjisi frekansla orantılı)
- Klasik RF: frekans ve güç bağımsız; sinyal yayılırken frekans sabit, amplitüd azalır (1/r²)
- Dalga boyu: λ = c/f — ters orantılı, her dalga tipi için geçerli

**DAC/ADC Bit Derinliği**
- Her bit ~6 dB dinamik aralık ekler; 14-bit ≈ 84 dB
- Amaç: quantization gürültüsünü kanal gürültüsünün altında tutmak

**Modülasyon Seçimi**
- QAM yüksek SNR'da: WiFi (1024-QAM), 4G (256-QAM)
- Uzayda düşük SNR → QPSK (2 bit/symbol) — gürültüye dayanıklı

**Binary Dosya Formatı**
- `.cf32` ve `.bin` birebir aynı içerik, sadece uzantı farkı
- `struct.pack("<ff", i, q)`: iki float32'yi little-endian binary olarak yazar
